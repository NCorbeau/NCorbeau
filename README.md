# Maciej Głownia

I’m a full-stack product engineer based in Warsaw. Previously at Kalepa and Appfire.

I build web applications and backend services with React, Angular, TypeScript, Python and PostgreSQL.

## Selected projects

- **[Kikit](https://github.com/NCorbeau/kikit)** — collaborative notes with offline editing, local persistence and explicit device/server save states. Built with React, TypeScript, Yjs and PostgreSQL. [Try Kikit](https://kikit.ncstudio.click).
- **[Mimit](https://github.com/NCorbeau/mimit)** — a Telegram assistant for household supplies, price tracking and restocking advice. A Python/FastAPI backend with PostgreSQL, durable background work and idempotent stock updates.
- **[StayFacts](https://github.com/NCorbeau/stayfacts)** — accommodation discovery near EV charging, with traceable sources and spatial matching. Python/PostGIS, Astro/Solid and Cloudflare Workers. Under development; the public demo uses synthetic data.
- **[NCStudio video renderer](https://github.com/NCorbeau/ncstudio-video)** — data-driven portrait videos with React, TypeScript and Remotion. Includes runnable quiz, ranking and captioned-video examples.
